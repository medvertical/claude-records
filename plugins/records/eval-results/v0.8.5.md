# Records Agent Tools Eval Results v0.8.5

Hosted API contract release.

## Goal

Make interactive hosted validation deterministic after a real Claude Code run exposed two ambiguities: the agent inferred an obsolete endpoint contract and guessed a workspace `serverId` when stateless validation failed.

## Changes

- Document `https://records.api.medvertical.com` as the canonical hosted base URL while preserving configurable staging and self-hosted URLs.
- Define `RECORDS_AUTH_TOKEN` as the interactive bearer-token variable and distinguish it from the conventional `RECORDS_API_KEY` CI secret name.
- Pin hosted validation to `POST /api/validation/validate-resource-detailed` and explicitly forbid adding or guessing `serverId`.
- Fail closed instead of silently switching to local validation when hosted validation was explicitly requested.
- Add a smoke-test contract covering the hostname, token variable, endpoint, and stateless boundary.
- Fetch complete Git history in Plugin CI so the existing release-tag consistency check can see published tags.

## Verification

- `npm run test:codex`
- `npm run test:claude`

## Release Decision

Ship only after the full `npm run check` gate passes and a synthetic Observation validates through the deployed hosted API without `serverId`.
