# Records Agent Tools Eval Results v0.8.6

Hosted API contract hardening release.

## Goal

Make hosted-mode selection and HTTP success semantics unambiguous so configured API validation remains deterministic and fails closed.

## Changes

- Treat a configured `RECORDS_API_URL` as hosted/API opt-in while continuing to enforce the resource privacy gate.
- Allow an explicit hosted-validation request to select the same contract, requiring the base URL to be configured before the call.
- Accept validation output only from `2xx` responses and classify every other HTTP status as a remote-validation failure.
- Forbid interpreting non-success response bodies as validation results or silently falling back to local validation after hosted/API mode is selected.
- Add smoke-test assertions for both API-selection paths and the complete non-`2xx` failure boundary.
